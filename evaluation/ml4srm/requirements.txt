# Python dependencies for the SHAP explainer.

# Install in ONE pip invocation (pip install -r), never as separate commands:
# sequential installs let each call re-resolve and downgrade earlier packages.
#
# Why numba and llvmlite are pinned even though nothing here imports them
# directly: shap depends on numba, and numba enforces a NumPy upper bound at
# import time, not only in its metadata. Leaving either side unpinned produced
#   ImportError: Numba needs NumPy 2.4 or less. Got NumPy 2.5.
# numba 0.61.0 declares numpy >=1.24,<2.2, which brackets the numpy pin below.
#
# The first six versions match the artefact Dockerfile so cluster runs and the
# container reproduce the same explanations.
