# Evaluations - ML4SRM

This directory contains the SRM-Catalog dataset, results, and logs of the three ML approaches evaluated the eXRM paper. <br>
It also contains the extracted test datasets from the OWSAP-Benchmark. <br>

The feature names are represented following the naming convention used below: <br>
Method (Mtd), Parameter (Param), Return (Rtn), Class (Cls), Contain (Ctn), Count (Cnt), Prefix (Pfx), Suffix (Sfx), Data-flow (Df), Starts (Strt), Name (Nm).
